# Dynamic Workflow Protocol

1. Validate the typed plan with `dw validate`.
2. Compile the plan with `dw compile` when a manifest review is required.
3. Execute with `dw run` and preserve `DW_*` markers.
4. Review with `dw review`.
5. Resume with `dw resume` only from durable run state.
6. Summarize with `dw summarize` for user-facing output.
